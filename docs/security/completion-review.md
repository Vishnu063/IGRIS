# Completion security review

Release acceptance is BLOCKED. Passing individual cloud checks does not mean production readiness.

The existing Guardian remains the sole authorization system. Native Hermes tools are empty and its actual dispatch is independently default-deny. The original three-tool subprocess retains typed allowlists, private workspace/descriptor containment, resource/deadline limits and Linux x86_64 kernel restrictions. New integration profiles use the same policy, ActionReview, ApprovalStore and one-use exact execution permits at their execution boundary. No unrestricted shell, Python, browser, filesystem, network, deployment, spending or external communication is exposed to the model.

Owner decisions bind immutable operation/arguments, actor, workspace, request/mission IDs, scope digest and expiry. Separate terminal or authenticated dashboard decisions are required. Sixty seconds applies to the owner's decision; approved slow profiles retain their five-minute total expiry. Rehashing, changed scope and replay cannot extend authority. Stop cancels pending snapshots; restart cannot automatically resume approvals. Unknown Docker create/cleanup results retain a private launch ledger and block later workers for operator review.

The final npm audit reported 173 affected n8n lock entries, including 6 critical and 78 high. These include dependency/meta-vulnerability entries, not independently exploited CVEs. Automatic `npm audit fix` suggested unsafe major changes/downgrades and was not applied. Current n8n scope and execution gates reject the pinned tree even with explicit startup flags. Its historical live calculation remains evidence of past operation, not a currently cleared integration. Patched dependencies, fresh audit, immutable pins and renewed live/isolation/cancellation tests are required before unquarantining.

OSV queried 105 installed Python package versions across Hermes/Mem0/MarkItDown with no reported advisories or query failures at the recorded time. This is a scoped database result, not absence-of-vulnerability proof. Native OS/kernel, Chromium/llama/Handy binary vulnerability coverage and full commercial license review are not complete. The license metadata inventory has 2205 entries, 32 unknown and custom/SEE LICENSE/enterprise entries requiring further review before redistribution. Upstream MIT/Apache/GPL/Sustainable Use notices are retained/documented; no actor voice cloning or paid feature activation occurred.

Logical chat/fact backups contain only validated completed dialogue and owner-approved scoped data. They exclude credentials, approvals, policy, active missions and vector indexes. Restore creates new private databases with no pending requests and a fresh empty approval store. A real approved-but-unused source action was denied against the restored store, and actual Hermes recovered the saved codename. This is data recovery, not restoration of execution authority. Old backups and orphaned facts may retain data: no forensic erasure guarantee is made.

Remaining boundaries: same-user/administrator process modification and local database rollback are not prevented; worker/Python objects are not security isolation from a hostile host owner. Docker administrators can bypass host controls. No independent complete sandbox certification is claimed. Model responses can be wrong, including specialist advice; supplied context, role definitions, documents and retrieved memories never grant permissions. Secrets filtering is pattern-based and cannot prove detection of every secret. Private SQLite/accounts/backups are not encrypted vaults. A hard crash can leave a reservation or owned ledger requiring explicit owner investigation rather than automatic replay.

Mac M1/ARM64 kernel controls, native microphone/playback and human English/Hindi/Marathi recognition quality remain unverified. The Mac preparation utility cannot enable assistant startup or substitute the verified x86 runtime. No privileged container, external model API, public endpoint, production deployment, client contact, main merge or paid service was used. Scope-specific evidence and final regression counts are in the completion reports and current integration matrix.
